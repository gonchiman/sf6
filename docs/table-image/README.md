# テーブル画像出力の仕様

このプロジェクトでテーブルの画像出力を作成・変更するときは [共通のテーブル画像出力仕様](../../instructions/shared/table-image.md) を読む。グラフ画像の配置・サイズは [グラフ画像出力の仕様](../chart-image/README.md) が扱い、表用の枠組みをグラフへ流用しない。

## SF6の表示・比較基準

- 表の基準部品と集計ルールには [テーブルの表示方針](../../instructions/table-ui.md) を適用する。画像化によって元の値・分母・比較対象を変えない。
- 系列色の定義には [比較系列の配色方針](../series-colors/README.md) を使う。表・凡例・プレビュー・PNGで同じ対応を使う。
- 画像名と保存先選択は [グラフ画像出力の画像名・保存操作の方針](../chart-image/README.md#画像名) に揃える。

## 実装状況と確認

- テーブルの画像保存機能・共通部品・SF6の見本画像は未実装で、適用済みページはない。仕様の保存を、機能の実装や既存ページへの適用と扱わない。
- 文字サイズの初期値・選択肢、配置の選択肢、幅・高さ・画素数上限は未実装。実装時に利用環境と要件を確認して共通定義へ集約し、定義元と検証方法を登録する。ページ側で上限や検証を無効にしない。
- 実装後に実在する部品・定義・見本への相対リンクと使い方を登録する。記載する入力・保存手順は実装時の設計であり、現在利用できるAPIと扱わない。
- 見本は実際の保存機能から生成し、対象ページ、入力条件、配置・文字サイズ・比率、再生成手順を登録する。数値や対象名は入力例とし、将来の出力へ固定しない。
- 変更時は共通仕様の確認項目に従い、画面・プレビュー・実PNGの一致、全文・全行・全列、共通文字サイズ、寸法・画素数の上限、分割前の比較基準・色尺度の維持を確認する。実装変更では関連テストとビルド、文書のみの変更では内容・参照先・適用範囲を確認する。
