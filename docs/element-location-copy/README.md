# ページ内のアドレスとコピー操作

## 用途と適用範囲

画面について変更や質問をするときに、その場所をチャットで指せるよう、ページ名と場所の表示名を1行でコピーする。

新しいページ・設定セクション・パネル・表・グラフ・表示形式の提案・設計・実装、既存ページを標準構造に移す作業、アドレスコピー自体の変更に適用する。新設する部分が既存部品の再利用であっても同様とする。

既存要素への遡及は依頼された範囲に限る。既存の列幅や軸を直す作業で周辺全体へコピー操作を追加する必要はない。個々の入力欄・ボタン・セル・データ点にはコピーを置かず、所属するセクションや結果のアドレスと画面の項目名で指す。

## 固定仕様と可変部分

アドレスはページ名から始め、その場所の識別に必要なセクション・タブ・パネル・表示形式の表示名を順につなぐ。各要素を` / `で区切り、全体を`〈〉`で囲む。

```text
〈Steam同時接続数 / 表示条件〉
〈Steam同時接続数 / 時間帯比較 / グラフ / 人数〉
```

- 画面と同じ名称の定義を使い、選択中のタブ・表示形式に追随する。内部ID、URL、検索語、対象キャラクターや期間などの入力値は含めない。同じ場所は設定値を変えても同じアドレスになるようにする。
- 親にコピー操作がなくても、子の場所を特定するのに必要な親の表示名は含める。画面にない区分名や不要な中間階層は作らない。
- コピー対象のページ名・階層・表示形式は入力として扱う。文字列の区切り方、コピー処理、状態表示は共通化し、ページごとに同じ処理を作り直さない。
- コピー内容を常時表示する欄や説明用のツールチップは追加しない。コピーは場所の識別に使い、条件付きURLの共有やデータの出力とは別の機能として扱う。

## 配置

設計時に「この場所について」と独立して指したいまとまりを決め、各対象のコピー位置と文字列を案に示す。実装時は各対象に1つのコピー操作を設ける。

| 対象 | コピー操作の配置と内容 |
| --- | --- |
| 独立した設定セクション | 見出し行の右端。ページ名と設定の見出し名を使う。リセットなどの操作はコピーの左に置く。 |
| 複数の結果タブ | タブ列の右端に1つ置く。選択中のタブ名を使い、表示形式があれば末尾に加える。 |
| 単一の出力 | 見出しや表示切り替えの行の右端。ページ名だけで場所を特定できる場合は、それだけをコピーする。コピーのためにタブや重複するページ見出しを作らない。 |
| 個別のパネル | パネル見出し行の右端。そのパネルを特定する親の階層とパネル名を含める。 |

画像保存と同じ行に置く場合は保存を左、コピーを右にする。ボタンの共通外観・押下領域はページ標準の画像保存ボタンとそろえる。表・グラフなどを画像や動画へ出力する場合は、コピー操作とアドレスを出力範囲から除く。

[ElementLocationCopyButton](../../src/components/ElementLocationCopyButton.tsx) の `segments` に、ページ名から順に画面上の表示名を渡す。部品がアドレスを組み立て、押下時にクリップボードへ書き込む。[共通スタイル](../../src/components/ElementLocationCopyButton.css)は通常28px、タッチ操作や狭い画面では44pxの押下領域を確保する。

```tsx
<ElementLocationCopyButton segments={[pageTitle, settingsTitle]} />
```

## 操作とアクセシビリティ

- ネイティブの`button`を使い、「対象の場所をコピー」と分かる読み上げ名を付ける。アイコンは読み上げの重複を避け、キーボードのフォーカス表示を維持する。
- コピー中・成功・失敗を判別できる状態を持つ。成功と失敗は読み上げ用の状態通知でも伝える。アイコンの切り替えで列幅を動かさず、失敗後は再試行できるようにする。
- 処理中の重複実行を防ぐ。コピー処理の開始後にタブや表示形式が変わった場合、古い文字列の成功・失敗を現在の場所の通知として出さない。
- クリップボードへの書き込みはユーザーのボタン操作から行い、利用不可や拒否を成功として扱わない。画面に失敗状態を示し、フォーカスを不用意に移動させない。

## 見本・適用状況と更新

[Steam同時接続数](../../src/components/SteamPlayerCountPage.tsx)は、上段の表示条件と、タブ列の右端にある選択中の結果からそれぞれ場所をコピーできる。ゲーム・期間・曜日を変更したときも、同じ場所を表示していれば同じ文字列になる。

実装時は対象の全タブ・表示形式と独立した設定セクションから実際にコピーし、貼り付けた文字列を確認する。必要な見本は`examples/`に保存し、対象ルートと操作手順を記載する。画面の表示名や構造を変更した際は、共通定義・コピー内容・見本を一緒に更新する。

## 変更時の確認

- 設計で決めた各まとまりをコピーして区別できること、設定値の変更前後で同じ場所の文字列が変わらないことを確認する。
- タブ・表示形式の切り替え、入力欄の操作、画像保存と干渉しないことを確認する。画面にないラベルや古い選択状態が混ざっていないことを確かめる。
- キーボード・狭い画面・タッチ操作で押せること、処理中・成功・失敗の通知、再試行、コピー中の表示切り替えを確認する。
- 保存画像や動画へボタンとアドレスが混入しないことを確認する。
- 文書だけの変更では、参照先の実在と相対パス、適用条件、未実装の部分との区別を確認する。
