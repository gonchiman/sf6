# グラフ画像出力の仕様

このプロジェクトでグラフの画像出力を作成・変更するときは [共通のグラフ画像出力仕様](../../instructions/shared/chart-image.md) を読む。画面上のグラフ、表だけの画像、スライド画像は対象外とする。

## SF6の配色と入力

- 系列の色は [比較系列の配色方針](../series-colors/README.md) に従い、画面・凡例・プレビュー・保存画像で統一する。
- 右上の条件には、出力するデータと一致する期間や対象などの主要条件を使う。
- 自然なグラフの高さは必要なラベル数やグラフ種類に応じて決める。兄弟プロジェクトの特定グラフの高さを、すべてのSF6グラフに固定適用しない。

## 画像名

画像名と保存先選択は [共通の画像名・保存操作の方針](../../instructions/shared/chart-image.md#画像名) に従う。

## 実装状況と確認

- 共通部品とSF6の見本画像は未作成。仕様を保存したことを機能の実装と扱わず、兄弟プロジェクトの部品が移植済みであるとも扱わない。
- 実装後に実在する部品・定義・見本への相対リンクと使い方を登録する。見本が採用済みデザインの参考か、実装から生成した確認用出力かを区別する。
- 変更時は共通仕様の確認項目に従い、プレビューに加えて実際に生成したPNGを確認する。共通部品やサイズ計算の変更に合わせてこの仕様と必要な見本も更新する。
