# 分析レポートの作成と確認

SF6のグラフ・表・統計を使って分析結果を文書として作成・修正するときに使う。対象、目的、出力形式、保存先、ページ構成は依頼に合わせる。

## 書き始める前に

今回の問い、図表と対応する集計データ、出典、観測期間・時刻帯、対象や絞り込みを確認する。分析に版がある場合は、結果を再現できる版やスナップショットを控える。勝率・使用率を扱う場合は、[勝率・使用率分析のルール](../../instructions/statistics.md)も参照する。

## 構成のひな形

| 位置 | 記載する内容 |
| --- | --- |
| 1ページ目の冒頭 | 対象と問いが分かる表題、期間と主要条件、問いへの答えを短く示す。 |
| 結論の直後 | 根拠にした図表に図題または表題を付ける。特徴を具体的な数値で示し、単位と分母が揃う場合は有用な比較を添える。 |
| 必要に応じた補足 | データの出典、集計単位・重み・有効数・欠測数、指標の定義、推定の前提、判断できる範囲を置く。 |

短い補足は1ページ目に収める。図表や文字が読みにくくなる場合は補足を後続ページへ移す。

## 数値と図表

- 観測値、計算した指標、そこからの解釈を区別する。式・分母・単位を確認し、条件や値は図表と同じ集計データ・実装で確かめる。取得できなかった枠、実測0、分母が0で算出できない割合を区別する。
- 例えばSteamの時間帯別平均なら、選択期間、タイムゾーン、平均に入った有効観測数を確認する。ランク分布なら取得期間と掲載アカウントの範囲を添え、概数として取得された値は概数として示す。比較する軸や単位が違う場合は、比較可能な指標に換算し、式と分母を明記する。
- 図の大きさ・点の数から度数や重みを逆算しない。分布の違いから原因まで主張する場合は、その因果関係を裏付ける別の根拠を示す。
- 図表を配置するときは値・目盛り・凡例・色の意味・縦横比を保つ。画像を作成・変更する手順は[グラフ画像出力](../chart-image/README.md)と[テーブル画像出力](../table-image/README.md)を参照する。

## 納品前の確認

1. 本文・図表・図題・出典が今回のデータと条件に一致しているか確認する。見本を使う場合はコピーで作業し、対象、日付、数値、結論を今回の内容に更新する。Googleドキュメントの原本を使う場合は、利用可能ならネイティブのコピーを使う。
2. ページ形式の文書は全ページを描画し、文字や軸ラベルの欠け、図表の変形・分割、図題だけの改ページ、空白ページを確認する。ローカル文書からGoogleドキュメントに変換した場合は変換前も確認し、最終のGoogleドキュメントはPDFに出力して全ページを再確認する。
3. 依頼された形式・保存先・共有範囲を確認して渡す。今後SF6用の見本を採用・更新するときは、承認された文書のコピー、対応する入力図表、最終文書から描画したページ見本を対応付けて保存する。
