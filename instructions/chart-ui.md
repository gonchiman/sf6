# グラフの操作と描画

画面上のグラフを提案・設計・実装・変更するときに適用する。

## 読み取りと操作

- 新しいグラフは、操作しなくても値の意味を読めるようにする。軸名、単位、系列名を示し、表示形式の切り替え、絞り込み、保存はグラフの外に置く。描画領域、目盛り、帯、凡例は原則として閲覧専用にする。
- 幅が足りない場合は、ラベルの折り返し、目盛りの間引き、横スクロールを使う。目盛りを間引く場合も対象の棒や観測値を残し、各項目の名前・値を表や読み上げでも確認できるようにする。
- 点や棒の詳細を選ぶなど、グラフ内の操作が要件にある場合は、その用途に必要な操作を設ける。マウスとキーボードの両方で結果を確認する。既存の [ランク分布](../src/components/RankDistributionChart.tsx) や [Steamのゲーム比較](../src/components/SteamPlayerCountComparisonCharts.tsx) の操作を変更するときは、そのページの要件を確認する。

## 棒グラフの集計と描画

- 集計側から描画側へ、項目のIDと順序、軸の意味と単位、丸める前の値、集計条件を渡す。描画側はこれらの項目からタイトル・軸名・条件を組み立て、表示済みの文字列から単位や集計方法を推測しない。割合には分母を明示し、人数・割合・指数を切り替えても、何を数えたかがわかる表示にする。[ランク分布の値と軸](../src/lib/rankDistributionChart.ts) と [Steamのゲーム比較集計](../src/lib/steamPlayerCountComparison.ts) を参照する。
- キャラクターのような分類、連続するMR区間、単独の数値を区別する。区間には上下限、境界の扱い、上限なしなどの情報を保持する。階級の変更は定義された境界から計算し、対応が保証されない階級同士を表示名で足し合わせない。[MR帯の区間とラベル](../src/lib/mrDistributionChart.ts) を参照する。
- 連続した区間を並べる棒は隙間を小さくし、単独の点やキャラクターなど独立した項目の棒は間隔を空ける。縦棒と横棒で同じ基準を使い、ゼロ件や欠損の階級も所定の位置に残す。
- 棒の長さの基準はゼロとし、符号を持つ指標では負の領域を含める。ゼロ件は有効な値として描き、未取得・比較不能は欠損として区別する。累積割合を提供する場合は順序と共通の分母が定義できる分布に限る。
- 左右に向けて二系列を比較する場合は、項目順と軸の尺度をそろえ、割合なら各系列の分母を示す。向きは描画で表現し、元の数値の符号を維持する。グラフ設定には対象のデータで意味を持つ選択肢を表示する。
- 強調表示が必要な場合は項目のIDで選択を保持し、該当するデータだけに適用する。選択を解除しても集計条件は維持する。
- 同じグラフを表や画像にも出す場合は、日時・適用条件・集計結果・系列IDをそろえる。画面とPNGは同じ描画処理を使い、軸・棒幅・選択の意味を保つ。画像保存を扱うときは [グラフ画像出力の仕様](../docs/chart-image/README.md)、色で比較対象を区別するときは [比較系列の配色方針](../docs/series-colors/README.md) を併用する。
