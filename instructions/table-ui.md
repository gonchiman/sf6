# テーブルの表示方針

このアプリのテーブルを新規作成・修正するときに適用する。

- 作り始める前に、既存ページにある用途の近いテーブルを確認し、既存のコンポーネントやスタイルを優先して使う。
- ユーザーから別の指定がない限り、外枠と縦横の罫線があるテーブルを標準とする。枠や縦罫線を省略した表示を初期案にしない。
- 枠と罫線は薄いグレーの1px線とし、色は共通の境界線の定義に揃える。ページごとに同じ色を個別定義しない。
- 見出しの背景、セルの余白、文字サイズ、文字・数値の配置は、採用済みの既存テーブルに揃える。
- 基準となるテーブルが未作成の場合は、最初に採用したテーブルを基準とし、共通スタイルと実在する参照先をこの仕様に登録する。前身の特定ページや未移植のCSSを、SF6に存在する基準として扱わない。

## 基準となる実装

- 共通の外枠・縦横罫線、見出し背景、セル余白、数字の配置は [table.css](../src/table.css) を使用する。
- 表示とスクロールの参照は [WinRateTable.tsx](../src/components/WinRateTable.tsx)、勝率表固有の固定列・セル選択は [win-rates.css](../src/win-rates.css) を確認する。
- スクロール領域には名前とキーボードフォーカスを付ける。行列の見出しには `scope` を付け、固定する見出しの背景と重なり順を保つ。

## 比較表の判定と共通化

比較表で最大値・同率の強調、共通部分の結合、転置や分割を作成・変更するときに適用する。

- 比較対象、指標、単位、対象期間、基準値・分母を定め、比較対象外の条件は見出しとして残す。表示を切り替えても元の数値や比較条件を変更しない。勝率・使用率の集計には [勝率・使用率分析のルール](statistics.md) も適用する。
- 最大値や同率は選択された全候補の未丸め値から判定し、表示桁で丸めて最大候補を決めない。同率は浮動小数点の丸め誤差だけ許容し、同率の候補をすべて示す。非表示の比較元を自動的に候補へ追加しない。
- 比較候補に欠損・不正値があれば、その比較単位は比較不能とする。欠損候補だけを除外して最大を選ばない。
- 共通の行・列をまとめる場合は、他の比較条件を揃えたうえで、対象範囲の全セルの未丸め値が一致することを確認する。欠損や表示桁だけの一致では結合せず、共通化した条件を見出しへ明記する。
- 最大候補の名称をまとめる場合も、名称の一致だけでなく、比較した全候補の元の値が一致することを確認する。
- 転置・上下配置・条件別分割でも、各値の比較元と分母を維持する。比較値を濃淡で表す場合は、同じ指標・比較条件の表全体で色尺度を揃え、分割した各表で再計算しない。系列の色の定義には [比較系列の配色方針](../docs/series-colors/README.md) を使う。
- 画面・コピー・計算詳細・保存画像へ、同じ設定・データ・表示状態を渡す。
