# 作業フォルダと開発サーバー

機能開発の最初の編集前に `git worktree list` で `main` の場所を確認する。機能の編集と検証は、その機能のブランチを開いた別の作業フォルダで行う。

| 起動する対象 | 起動元とポート |
| --- | --- |
| 普段使うSF6 | 利用者が指定したクローン先で `main` を開き、原則5173番を使う。 |
| 開発中の機能 | 対象ブランチの作業フォルダで、5173番以外の空きポートを使う。機能開発の続きで「起動」とだけ指定された場合はこちらを開く。 |

- 起動・再起動時は、起動元で `git rev-parse --show-toplevel` と `git branch --show-current` を確認する。`main` の場所を変える場合は、関係する作業フォルダの未コミット変更を先に確認し、保持して切り替える。
- 例として、`main` はそのルートで `npm run dev -- --host 127.0.0.1 --port 5173 --strictPort` を実行する。機能確認用ならポート番号を空いている番号に替える。
- 指定ポートが使用中なら、配信しているプロジェクトと作業フォルダを確認する。同じ対象なら既存サーバーを使う。他プロジェクトのサーバーと併用する場合は空きポートで起動し、実際のURLを案内する。
- [Viteのベースパス](../vite.config.ts)は `/sf6/`。起動時に指定したホスト・ポートで目的のルート（例 `/sf6/#steam-player-count`）を開き、SF6のページ名と内容を確認する。
