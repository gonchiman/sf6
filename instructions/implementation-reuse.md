# 既存機能・UIの調査と再利用

このアプリの機能・UIの追加や修正について、案を提示するとき、設計するとき、または実装するときに適用する。案の提示だけの場合も、作業を始める前に [共通の調査・再利用手順](shared/implementation-reuse.md) を読み、以下の固有方針と併用する。

- 初期構築に限らず、提案・設計・実装の各段階で、参照できる範囲の兄弟プロジェクト `arknights_2` も継続的な調査対象にする。SF6側の既存実装を先に確認し、今回の用途に関係するUI・スタイル・共通処理・仕様から再利用候補を探す。参照できない場合はその制約を示し、未確認の部品が使えるとは断定しない。
- 兄弟プロジェクトの実装を調べる前に、そのルート `AGENTS.md` と作業に該当する参照先の指示・仕様を明示的に読む。プロジェクトの参照用フォルダーに追加したことだけで、読み込み済みと扱わない。参照元は設定されたフォルダーやユーザーが示した場所から確認し、個人フォルダーの絶対パスをこの仕様に固定しない。
- 他プロジェクトから採用するコード・仕様はこのリポジトリ内に配置し、必要な依存関係も確認する。別プロジェクトのローカルパスに実行・ビルド・仕様参照を依存させない。
- 兄弟プロジェクトは参照元として扱い、そのファイル変更も依頼された場合に限り行う。継続参照の指定を、依頼範囲を超える一括移植やアプリ実装の開始指示として扱わない。
